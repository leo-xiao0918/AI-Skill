# 图像质量评估与预处理

## 1. 评估维度与阈值

| 维度 | 良好 | 需预处理 | 判定手段 |
|---|---|---|---|
| 分辨率 | ≥ 300 DPI | < 150 DPI | 读 EXIF 或按像素密度估算 |
| 文字高度 | ≥ 30 px | < 20 px | 目测或连通域统计 |
| 倾斜角 | < 1° | > 3° | `preprocess_image.py --report-only` |
| 清晰度 | 边缘锐利 | 明显模糊 | 拉普拉斯方差，低于 100 视为模糊 |
| 背景 | 均匀白底 | 灰底、阴影、噪点 | 灰度直方图双峰是否明显 |

任一维度落入「需预处理」区间时，须**先向用户说明将要执行的处理方式**，取得默许后再处理。

## 2. 预处理配方

按下列顺序组合，每一步都可单独关闭：

1. **灰度化** — 统一为单通道，降低后续计算量。
2. **去噪** — 中值滤波（3×3），抑制椒盐噪点；扫描灰底用自适应阈值处理。
3. **纠斜** — 估计文本基线倾角后反向旋转，旋转后以白边填充。
4. **增强对比** — 直方图均衡或线性拉伸，拉开文字与背景的灰度差。
5. **二值化** — 仅对纯黑白印刷体启用；含灰度图或彩色图形时禁用，避免丢失细节。
6. **放大** — 对低分辨率图按 2× 或 3× 重采样（Lanczos），提升小字号可辨度。

含彩色图形、照片或手写批注的图，跳过二值化，保留原始色彩。

## 3. 命令行用法

```bash
# 仅评估质量，不写出文件
python scripts/preprocess_image.py <image> --report-only

# 完整预处理（自动决策，推荐）
python scripts/preprocess_image.py <image> --out <dir>

# 手动指定步骤
python scripts/preprocess_image.py <image> --out <dir> --deskew --denoise --scale 2

# 强制二值化（仅纯黑白印刷体）
python scripts/preprocess_image.py <image> --out <dir> --binarize
```

输出文件命名为 `<原名>_pre.png`，与质量报告一同打印到终端。

## 4. 升级与放弃准则

- 预处理后仍有条目落在「不可识别」区间时，**停止自动处理**。
- 在置信度报告中把这些条目标为「不可识别」，并询问用户是否提供清晰原件或更高分辨率扫描。
- 不得因为「看起来像某个公式」就补全内容；连续两轮预处理仍失败的图，直接转入人工确认环节。

## 5. PDF 输入补充

- 先用 `extract_pdf.py` 渲染为 PNG，渲染 DPI 建议 200–300。
- 若 PDF 含文字层，把内嵌文本与识别结果对照，用于校验数字与符号。
- 矢量 PDF 优先尝试提取原始矢量图形，可减少几何图的重建误差。
